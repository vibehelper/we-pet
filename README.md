# WePet 宠物医院门户

WePet 宠物医院的官方门户网站：服务介绍、医生团队、收费标准、在线预约挂号、常见问题与联系方式，一页看全。

## 在线预览

直接用浏览器打开 `index.html` 即可，无需构建、无需后端。

```bash
# 本地起一个静态服务（任选其一）
python3 -m http.server 8000
npx serve .
```

然后访问 http://localhost:8000

## 页面结构

| 区块 | 内容 |
| --- | --- |
| 首页横幅 | 医院定位、24h 急诊电话、预约入口 |
| 诊疗服务 | 全科门诊、疫苗、检验、影像、外科、住院、牙科、美容 8 项 |
| 就诊流程 | 预约 → 到院 → 诊疗 → 取药复诊 |
| 医生团队 | 4 位执业兽医师介绍与坐诊时间 |

| 主人评价 | 3 条真实口碑 |
| 常见问题 | 手风琴折叠：首诊准备、改期、疫苗注意、夜间急诊收费等 |

## 技术

- 纯静态：HTML + CSS + 原生 JS，零依赖、零构建
- 响应式：桌面 / 平板 / 手机三档布局，移动端汉堡菜单
- 预约数据仅存在用户自己浏览器里（localStorage），不上传服务器

## 项目规划

### 项目简介

WePet 是一个面向宠物医院的线上门户 + 诊疗管理系统。主人可以在网上了解医院服务、查看医生排班、在线预约挂号、查疫苗与体检记录；医院可以在后台管理预约、病历、疫苗档案与收费。当前 v1 是纯静态门户（服务介绍 + 预约表单演示），后续按下面的技术栈演进为全栈应用。

### 技术栈

- **前端**：React（+ React Router、Axios）
- **后端**：Node.js（Express、JWT 鉴权）
- **数据层**：Hermes
- **部署**：静态门户可直接托管；全栈版前后端分离部署

### 数据表规划

| 表名 | 用途 | 核心字段 |
| --- | --- | --- |
| owners | 主人 | id、姓名、手机号、邮箱、地址、created_at |
| pets | 宠物档案 | id、owner_id、名字、种类、品种、性别、生日、体重、芯片号 |
| vets | 医生 | id、姓名、职称、专长、简介、坐诊时间 |
| services | 服务项目 | id、名称、分类、描述、价格、时长 |
| appointments | 预约挂号 | id、pet_id、owner_id、vet_id、service_id、日期、时段、状态、症状描述 |
| medical_records | 病历 | id、pet_id、vet_id、appointment_id、诊断、用药、医嘱、created_at |
| vaccines | 疫苗记录 | id、pet_id、疫苗名、针次、接种日期、下次到期、vet_id |
| orders | 订单 / 收费 | id、owner_id、appointment_id、金额、支付状态、paid_at |

### 路线图

1. **v1（已完成）**：静态门户上线，服务、团队、收费、预约表单演示
2. **v2**：React 重构前端 + Node.js API，预约、改期、取消走真实接口
3. **v3**：接 Hermes 数据层，病历、疫苗档案、医生排班落库
4. **v4**：在线支付、短信通知、主人端查报告与体检记录

## 待接后端（下一步）
