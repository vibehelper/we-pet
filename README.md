# WePet 宠物医院门户

WePet 宠物医院的官方门户网站：服务介绍、医生团队、收费标准、在线预约挂号、常见问题与联系方式，一页看全。

## 在线预览

直接用浏览器打开 `index.html` 即可，无需构建、无需后端。

```bash
# 本地起一个静态服务（任选其一）
python3 -m http.server 8000
npx serve .
```

然后访问 http://localhost:8000

## 页面结构

| 区块 | 内容 |
| --- | --- |
| 首页横幅 | 医院定位、24h 急诊电话、预约入口 |
| 诊疗服务 | 全科门诊、疫苗、检验、影像、外科、住院、牙科、美容 8 项 |
| 就诊流程 | 预约 → 到院 → 诊疗 → 取药复诊 |
| 医生团队 | 4 位执业兽医师介绍与坐诊时间 |
| 收费标准 | 挂号、体检、疫苗、手术等 9 项明码标价 |
| 预约挂号 | 表单校验 + 预约号生成，记录保存在浏览器 localStorage |
| 主人评价 | 3 条真实口碑 |
| 常见问题 | 手风琴折叠：首诊准备、改期、疫苗注意、夜间急诊收费等 |
| 联系我们 | 地址、电话、门诊时间、停车信息 |

## 技术

- 纯静态：HTML + CSS + 原生 JS，零依赖、零构建
- 响应式：桌面 / 平板 / 手机三档布局，移动端汉堡菜单
- 预约数据仅存在用户自己浏览器里（localStorage），不上传服务器
